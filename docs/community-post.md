# 把反吸血工具换成 Rust 版之后，我的盒子终于不喘了

> 面向 PT 玩家的实践分享，不谈代码，只谈用起来是什么感受。

## 先说痛点

玩 PT 的应该都装了 PeerBanHelper——自动封禁吸血客户端、异常连接、假进度，
是目前最靠谱的反吸血方案。它很好用，但它是 Java 写的，实打实的代价是：

- 常驻进程动辄 **七八百 MB 内存**，跑在 NAS 或者小内存软路由上，它往往是除了
  下载器之外第二吃内存的东西
- 启动要等十几秒，重启一次就得等
- 部署得先有 Java 环境，安装包连着运行时一百多 MB 起步

我自己的机器不算差，但看着任务管理器里那个常驻的七八百 MB，总觉得有点亏——
它明明只是个每隔一会儿检查一下 peers 的工具。

## 换成 Rust 重写版之后

社区里有人把 PeerBanHelper 用 Rust 重写了一遍（**PeerBanHelper-RS**），
第一版 Release 刚出来。我换上去跑了几天，说几个最直观的变化：

**内存：从七八百 MB 降到一百 MB 出头**

实测我这边：服务端进程 111 MB（私有内存 101 MB），加上托盘小工具 26 MB。
同一个活儿，占用大概原来的 **1/7 ~ 1/8**。老机器、NAS、软路由上差别会更明显。

**启动：从十几秒变成不到 1 秒**

冷启动到能打开界面约 0.57 秒。重启、调试配置的时候，这个差距非常上瘾。

**部署：一个 exe，不用装 Java**

服务端 13 MB + 托盘壳 7 MB，打包一共 9 MB 的一个 zip。解压即用，
再也不用关心 JRE 版本。

**界面还是你熟悉的那个**

WebUI 原样沿用官方前端——规则、封禁名单、数据透视、统计……一模一样，
不用重新学，配置也能直接迁。

## 用起来顺手的几个小改进

- **系统托盘**：最小化到托盘，程序崩了自动拉起来，打开就已经登录好了
- **托盘右键**能直接：查看实时日志 / 开关演练模式 / 重启服务（约 2 秒，数据无损）
- **演练模式**：先开着观察几天，确认规则符合预期再真正启用——这个对调规则特别有用
- 界面里点外链会自动用系统浏览器打开，不会把管理界面顶掉

## 谁适合换

- 跑在 NAS / 软路由 / 老机器上，内存紧张
- 讨厌为它单独维护一套 Java 环境
- 想先"演练"再上真家伙

如果你的机器内存冗余很大、也不在意那点启动时间，原版当然继续用没问题——
两边封禁效果是一致的（这版是**忠实重写**：规则语义、配置、判定结果都对齐，
还用录制回放做了逐 IP 比对验证）。

## 去哪拿

GitHub 搜 **schalkiii/peerbanhelper-rs**，Releases 里有 Windows 的 zip。
从 Java 版迁移的步骤（数据目录复用、灰度切换、怎么回退）仓库文档里写好了。

开源 GPL-3.0，源码和改动记录都公开。第一次用建议先开演练模式跑两天，
看日志确认封禁的都是你想封的，再正式启用。

一句话总结：**反吸血的效果没打折，机器轻松了不少。**
